# Reference Projects and Gap Analysis

We will learn from these projects and standards without copying their code or positioning:

| Project | Strength to study | Opportunity for MCP RedFlag |
|---|---|---|
| [Snyk agent-scan](https://github.com/snyk/agent-scan) | Agent security scanning and developer workflow | Add a vendor-neutral reproducible adversarial benchmark |
| [Cisco mcp-scanner](https://github.com/cisco-ai-defense/mcp-scanner) | MCP inspection and security checks | Measure behavioral impact, not only findings |
| [Ant Group MCP-Security](https://github.com/antgroup/MCP-Security) | Broad MCP security research/tooling | Publish small deterministic fixtures and evidence packs |
| [GenSecAI mcpscc](https://github.com/gensecaihq/mcpscc) | Detection coverage and SARIF/DevSecOps | Add controlled runtime experiments and replay |
| [eSentire MCP Scanner](https://github.com/eSentire-Labs/mcp-scanner) | Server assessment methodology | Standardize comparative scoring and independent reproduction |

## Our wedge

A safe “attack laboratory + benchmark specification + evidence format” that complements scanners. Success is not the number of checks; it is reproducible proof of whether an agent changed behavior under a known attack.
