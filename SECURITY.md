# Security and Responsible Use

SEKHMET RED is an **alpha defensive research tool**. Deterministic findings still require human review before operational decisions.

## Reporting a vulnerability

Do not publish exploitable details, credentials, private evidence or victim information in a public issue. Contact the maintainer through the professional links on the GitHub profile and provide a minimal, redacted reproduction.

## Rules of use

- Test only systems and data you own or are explicitly authorized to assess.
- Never upload secrets, personal data or active malicious payloads.
- Use synthetic or safely redacted fixtures in tests and examples.
- Treat scores and model outputs as decision support, not proof.
- Preserve source attribution, uncertainty and human review.

Public disclosure should occur only after a reasonable remediation window.
